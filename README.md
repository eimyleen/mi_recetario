# Dulce Recetario

Recetario web desarrollado con React y Vite que permite consultar recetas de postres, visualizar sus imágenes y conocer sus ingredientes y preparación.

## Características

- Listado de cinco recetas de postres.
- Pestaña para seleccionar una receta.
- Pestaña para consultar los detalles de la receta seleccionada.
- Imágenes y descripciones de cada postre.
- Listas de ingredientes e instrucciones de preparación.
- Interfaz sencilla e intuitiva.

## Recetas disponibles

1. Pastel de chocolate.
2. Cheesecake de fresa.
3. Brownies de chocolate.
4. Flan de vainilla.
5. Galletas con chispas de chocolate.

## Tecnologías utilizadas

- React: creación de la interfaz.
- Vite: herramienta de desarrollo y compilación.
- JavaScript: funcionalidad de la aplicación.
- CSS: estilos y diseño visual.

## Requisitos

- Node.js y npm.
- Visual Studio Code (recomendado).
- Un navegador web actualizado.

## Instalación y ejecución

1. Clona el repositorio:

   ```bash
   git clone https://github.com/eimyleen/mi_recetario.git
   ```

2. Entra en la carpeta del proyecto:

   ```bash
   cd mi_recetario
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```

5. Abre en el navegador la dirección local que muestre la terminal.

## Objetivo del proyecto

Crear un recetario web sencillo que permita seleccionar postres y consultar fácilmente la información necesaria para prepararlos.
